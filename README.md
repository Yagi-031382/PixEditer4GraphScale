# Pixel Color

画像上のピクセルをクリックし、そのピクセルと完全に同じ RGBA 値の全ピクセルを指定色（不透明）または透明に変更する、GitHub Pages 用の静的 Web ツールです。画像をサーバーに送信しません。

## 使い方

1. 画像ファイルを開くか、プレビューにドラッグ＆ドロップします。
2. 画像のピクセルをクリックして対象色を選択します。拡大表示もできます。
3. 置き換え先の色、または「透明にする」を選び、置き換えボタンを押します。
4. 「PNG で保存」で元のピクセル寸法の画像をダウンロードします。

直前の操作を1回取り消せます。「最初の画像に戻す」も利用できます。透明度を含む完全一致のため、JPEG の圧縮やアンチエイリアスによる近似色は別の色として扱います。PNG 出力に元画像のメタデータは保持しません。アニメーションは先頭フレームのみ、画像サイズは1,600万ピクセル以下に対応します。

## ローカル開発

追加パッケージは不要です。Node.js 24（テスト）と Python 3（ローカル配信）を使用します。

```sh
npm test
npm start
```

ローカルでポート8000にアクセスしてください。ES Modules を使用するため HTML ファイルの直接オープンではなく HTTP サーバーを使います。

## GitHub Pages 公開

リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。`main` にプッシュすると `.github/workflows/pages.yml` がテストと公開を実行します。依存パッケージ、ビルド処理、API キーは不要です。相対パスを使っているためプロジェクト Pages のサブパスでも動作します。

## 複数色と近い色相の選択

画像を続けてクリックすると、異なる色を複数追加できます。同一 RGBA 値の色は重複追加しません。各色の「削除」と「選択をすべて解除」で選択を解除できます。

選択色ごとの「似た色相も対象」を ON にすると、色相差が指定した許容差以内のピクセルも置換対象になります（初期値 ±15°、0〜60°に調整可能）。色相は円環として比較するため、赤の0°と360°付近も近い色として扱います。このモードでは明度・彩度・アルファ値の差を問いません。ただし白・黒・グレーなど色相のない色や完全透明色は RGBA 完全一致のみです。OFF の色は従来どおり RGBA 完全一致です。

選択したすべての色の対象を合算し、重複ピクセルは一度だけ置き換えます。置き換え先は共通の1色または透明です。編集・取り消し・元画像への復帰後は選択を解除します。
